# 第 8 天 · 第 8 题：React 虚拟列表与动态行高

**评分：85/100**

## 1. 虚拟列表原理（40/45）

虚拟列表通过 scrollTop 和容器高度计算可见索引，只渲染可见行及少量 overscan 行，利用占位总高度和定位偏移维持滚动体验。核心优化是降低实际 DOM 数量，而非仅计算高度。例如十万条数据中可能只需同时挂载几十条。

## 2. 动态行高（45/55）

先使用估算行高布局，渲染后通过 ResizeObserver 测量实际行高，更新高度缓存、元素偏移与总滚动高度。动态行高不能直接用 floor(scrollTop/itemHeight)，可维护前缀和及二分查找快速定位起始索引：

```text
行高：[40,80,55,120]
起点：[0,40,120,175]
```

如果当前视口上方某行高度增加 30px，通常应将 scrollTop 相应增加 30px，避免当前可见内容跳动；如果变化发生在视口下方，一般无需补偿。测量后不应无条件修改 scrollTop。

## 小结

用户正确提出了估算行高、ResizeObserver 实测、scrollTop 补偿；需要补充索引结构与补偿条件。
