# 第 6 题：答题与点评

## 第一轮
用户认为 qiankun 与 Module Federation 不冲突，qiankun 适合技术栈无关接入，对 MF 不熟。样式隔离建议 CSS 前缀与 qiankun 隔离能力；共享依赖建议 Monorepo；主应用通过路由实例供子应用跨应用跳转；迁移应考虑业务和团队阻力。

点评：区别应用级治理和跨构建模块共享；Monorepo 依赖统一安装不等于运行时共享；路由推荐稳定的导航抽象，而非直接暴露宿主路由实例；迁移应量化收益、故障率与迁移成本。

## 第二轮
用户建议用 MF 或 externals 共享 React 18，但不强制不同 React 大版本共享，原因是 API 兼容风险。对部署后白屏不清楚。

点评：版本兼容判断正确，还要考虑 React 实例一致性、React/React DOM 配套。白屏优先检查网络资源、缓存版本、qiankun 生命周期和运行时兼容。发布流程应先部署资源再切入口、保留旧产物、灰度和回滚。

## 模拟评分
75/100。需加强 MF 运行时、灰度发布、微前端故障定位。
