## 追问

子应用 A 发布 v2，CDN HTML 已更新且配置 `no-cache`，用户不刷新主应用，只在 A、B 间切换仍看到 v1。为什么？如何处理？

### 用户原始回答

> 1. 可能是子应用的index.html被缓存了,我先清楚DNS缓存试一下

### 评价

- 入口 HTML 被缓存是一种可能性，但题目重点是加载器的 JavaScript 内存缓存与运行时版本更新。
- DNS 缓存保存域名解析结果，通常与入口 HTML 是否更新无关。
- 应先检查 Network 是否出现新的入口请求，再分别定位 HTTP/CDN 缓存、qiankun 加载器缓存和主应用入口配置。
